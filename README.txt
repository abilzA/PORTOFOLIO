# Portfolio — Muhammad Nabil Fitterzon

Website portofolio satu halaman dengan desain putih dan biru navy.

## Menjalankan secara lokal
Buka `index.html` menggunakan browser.

## Deploy gratis ke Netlify
1. Masuk ke Netlify.
2. Pilih Add new site → Deploy manually.
3. Unggah folder hasil ekstrak ZIP ini (folder yang berisi `index.html`).
4. Netlify akan memberikan tautan website.

## Sebelum dipublikasikan
- Tambahkan alamat email dan nomor kontak pada bagian Kontak jika ingin ditampilkan.
- Periksa kembali daftar teknologi dan deskripsi proyek agar sesuai dengan kontribusi serta kemampuan aktual.
- Tambahkan tautan demo untuk proyek jika sudah tersedia.
